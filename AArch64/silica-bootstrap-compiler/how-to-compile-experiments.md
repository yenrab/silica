# How to Compile and Run Silica Experiments

This guide explains how to compile and run Silica programs using the bootstrap compiler.

## Prerequisites

### 1. Build the Compiler

First, build the Silica bootstrap compiler:

```bash
# Navigate to the compiler directory
cd silica-bootstrap-compiler

# Run the build script (recommended)
./build_bootstrap.sh

# Or build manually
cargo build --release
```

### 2. Set Up LLVM Environment

If you have LLVM 15 installed, set up the environment:

```bash
# From the Silica Language root directory
source ../setup_silica.sh
```

This adds LLVM 15 to your PATH and verifies it's working.

## Basic Compilation Workflow

### Compile a Silica Program

```bash
# Basic compilation (outputs to output.bc)
./target/release/silica-boot experiments/hello.silica

# Specify custom output file (.bc for bitcode, .ll for text)
./target/release/silica-boot experiments/hello.silica hello.bc
./target/release/silica-boot experiments/hello.silica hello.ll

# Compile with optimization
./target/release/silica-boot experiments/hello.silica --opt aggressive

# Compile with module search paths
./target/release/silica-boot experiments/main.silica --search-path ../experiments
```

### Run the Compiled Program

```bash
# Execute LLVM bitcode or text IR with lli
lli output.bc    # Preferred: smaller and faster
lli output.ll    # Also works: human-readable format

# Check the exit code (program return value)
echo "Exit code: $?"
```

## Compiler Options

### Optimization Levels

```bash
# No optimization (default)
./target/release/silica-boot program.silica --opt none

# Basic optimizations
./target/release/silica-boot program.silica --opt basic

# Aggressive optimizations
./target/release/silica-boot program.silica --opt aggressive
```

### Module Search Paths

```bash
# Add search paths for imports
./target/release/silica-boot program.silica --search-path src --search-path lib

# Multiple paths
./target/release/silica-boot program.silica -I src -I lib -I modules
```

## Understanding the Output

### LLVM IR Formats

The compiler can generate LLVM IR in two formats:

#### Binary Bitcode (`.bc`) - Preferred
- Compact binary format
- Faster to process and load
- Smaller file size
- Standard LLVM bitcode format

#### Text Format (`.ll`) - Human-Readable
- ASCII text format
- Readable and debuggable
- Larger file size
- Converted to bitcode using `llvm-as`

Example LLVM IR output (shown in both formats):

```llvm
; Module: silica_module
; Generated by Silica Bootstrap Compiler

; External function declarations
declare i8* @malloc(i64)
declare void @free(i8*)

; Silica runtime functions
declare i8* @silica_region_create()
declare i8* @silica_region_alloc(i8*, i64)
declare i64 @silica_region_read(i8*)
declare void @silica_region_write(i8*, i64)
declare void @silica_region_destroy(i8*)

define i64 @add(i64 %x, i64 %y) {
  ; Parameter x: %x
  ; Parameter y: %y
  %t22 = add i64 %x, %y
  ret i64 0  ; Placeholder return
}

define i64 @main() {
  %t27 = call i64 @add(i64 40, i64 2)
  ret i64 0  ; Placeholder return
}
```

**Note:** Function bodies currently return placeholder values (0). The LLVM IR structure is correct, but actual computation logic needs implementation.

### Execution with lli

`lli` (LLVM Interpreter) executes the LLVM IR directly:

```bash
lli program.ll
```

- Exit code 0 = success
- Non-zero exit codes = program return values or errors

## Troubleshooting

### Compiler Won't Build

**Problem:** `cargo build` fails
**Solution:**
```bash
# Clean and rebuild
cargo clean
cargo build --release

# Or use the build script
./build_bootstrap.sh
```

### LLVM Not Found

**Problem:** `lli: command not found`
**Solution:**
```bash
# Source the setup script
source ../setup_silica.sh

# Or manually add LLVM to PATH
export PATH="$HOME/1TB/llvm-15/bin:$PATH"
```

### Module Import Errors

**Problem:** "Module not found" errors
**Solution:**
```bash
# Add search paths
./target/release/silica-boot program.silica --search-path ../experiments

# Check file exists
ls ../experiments/module_name.silica
```

### lli Execution Errors

**Problem:** "Bad module" or function not found errors
**Solution:**
- Check that the `.ll` file was generated correctly
- Ensure LLVM 15 is being used (not a different version)
- Verify the program doesn't use unimplemented features

### Permission Errors

**Problem:** "Operation not permitted" when compiling
**Solution:**
- Check file permissions in the experiments directory
- Ensure you have write access to the output location
- Try running in a different directory

## Current Limitations

1. **Placeholder Implementations**: Function bodies return 0 instead of actual computations
2. **Limited Runtime**: Actor system and effects are declared but not fully implemented
3. **Text IR Only**: Binary bitcode generation has linking issues on macOS
4. **No Debugging**: Limited debugging support in the LLVM output

2. **Try Different Optimizations**: Compare output with different optimization levels
3. **Explore Modules**: Experiment with importing and using modules
4. **Check the Specification**: Refer to `../silica-specification.md` for language details

## Getting Help

If you encounter issues:

1. Check this guide for common solutions
2. Look at the build script output for error messages
3. Verify LLVM setup with `lli --version`
4. Check that experiment files exist and are readable

The Silica compiler is under active development, so some advanced features may not work yet. Focus on the core language features that are implemented!
