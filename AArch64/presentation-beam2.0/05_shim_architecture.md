## BEAM Compatibility APIs

**Process Management:**
```silica
// Silica implementation of BEAM process primitives
fn spawn_beam_process(fun: beam_term) -> proc[beam_process] beam_pid {
    let actor = spawn_actor(initial_state, beam_process_behavior)
    beam_pid{actor_ref: actor, monitor_refs: []}
}

fn send_beam_message(pid: beam_pid, msg: beam_term) -> proc[beam_process] unit {
    send(pid.actor_ref, msg)
}
```

**Message Handling:**
```silica
// Pattern matching that BEAM developers expect
fn receive_beam_message() -> proc[beam_process] beam_term {
    recv() match {
        beam_msg -> beam_msg
        _ -> receive_beam_message()  // Tail recursive
    }
}
```

## Transparent Native Compilation

**For Existing Code:**
- **Zero code changes required** - existing BEAM code compiles to native
- Same OTP behaviors and patterns work unchanged
- Compatible standard library APIs preserved

**For Language Implementers:**
- Templates generate complete compilers that use Silica runtime to process source files (.ex, .erl) into AArch64 libraries (.a, .so)
- No complex AST-to-AST translation - direct compilation using Silica runtime APIs
- Compiles both language standard libraries and business user code to native AArch64 libraries

## Technical Implementation Details

**Template-Generated Binding Modules:**
```silica
// Generated by silica-lang-template
// elixir_silica_bindings.silica
effect concurrency_eff = [concurrency]
effect io_eff = [device_io]
effect file_io_eff = [device_io, mem(normal)]

// Process creation binding
fn spawn_elixir_process(func: fn() -> unit) -> proc[concurrency_eff] actor_ref<unit> {
    silica::actor::spawn(func)  // Direct Silica API call
}

// Message conversion binding
fn send_elixir_message(pid: actor_ref<term>, term: term) -> proc[concurrency_eff] unit {
    silica::actor::send(pid, term);  // Direct Silica API call
}

// Memory allocation binding
fn allocate_elixir_binary(data: string) -> proc[file_io_eff] silica::memory::Ref {
    silica::memory::alloc_binary(data)  // Direct Silica API call
}

// Effect tracking binding
fn with_elixir_io_effect<F, R>(func: F) -> proc[io_eff] R
where F: fn() -> R {
    silica::effect::with_effect(silica::effect::IO, func)  // Direct Silica API call
}
```

**Language Compiler Integration:**
```silica
// In elixir_compiler.silica
use elixir_silica_bindings::*;

// Elixir spawn syntax compiles to direct binding
// Elixir: spawn(fn -> IO.puts("hello") end)
// Compiles to: spawn_elixir_process(|| println("hello"))

fn compile_elixir_spawn(ast: elixir_spawn) -> silica_code {
    let func = compile_elixir_function(ast.function);
    quote! {
        spawn_elixir_process(fn() -> {
            #{func}
        })
    }
}
```

**Cross-Language Interoperability:**
```silica
// Generated FFI bindings for language interoperability
effect ffi_eff = [concurrency, device_io]

// Elixir calling Erlang function
fn call_erlang_from_elixir(module: string, function: string, args: list<term>) -> proc[ffi_eff] term {
    let erlang_module <- silica::ffi::load_erlang_module(module);
    let erlang_func <- erlang_module.get_function(function);
    let silica_args = args |> map(convert_elixir_to_silica_term);
    let result <- silica::ffi::call_erlang_function(erlang_func, silica_args);
    convert_silica_to_elixir_term(result)
}

// Erlang calling Elixir function
fn call_elixir_from_erlang(module: string, function: string, args: list<term>) -> proc[ffi_eff] term {
    // Template-generated conversions for Erlang to Elixir
    let elixir_module <- silica::ffi::load_elixir_module(module);
    let elixir_func <- elixir_module.get_function(function);
    let silica_args = args |> map(convert_erlang_to_silica_term);
    let result <- silica::ffi::call_elixir_function(elixir_func, silica_args);
    convert_silica_to_erlang_term(result)
}
```
